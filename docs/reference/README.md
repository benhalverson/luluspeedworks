# Reference scope

These documents preserve the reviewed launch specification and selected B design as of 2026-09-20. Historical local paths describe source provenance, not runtime dependencies. The design comparison preserves rejected alternatives for context; the application implements B only.

Issue #13 and the repository README supersede older stack text: this repository is frontend-only, uses Biome exclusively and pins Zod 3.25.76. The original Hono Worker and new health endpoint requirements do not apply. Future API and agent work is separately scoped; endpoint changes belong in `3dprinter-web-api` with its existing health endpoint. Broader launch acceptance criteria are not claimed by this scaffold.

The reference documents describe historical plans and broader commerce milestones. See the [current source map](../../README.md#source-map) for implemented storefront, account, recovery and admin draft capabilities. No reference directory or prototype is needed to install, build, test or run this application.
